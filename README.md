## 🧾 What is This?

**Smart Bill Splitter** is a pure frontend web app that solves the most annoying problem in group outings — *who owes who what?* Add members, log expenses across categories, apply tips and taxes, and instantly see a clean settlement summary. Everything saves in your browser — no login, no backend, no fuss.

> *"Bhai kitna hua mera?"* — Never again. 💀

## 🧮 Split Logic Explained

### Equal Split
```
  Total Bill = Amount + (Amount × Tip%) + (Amount × Tax%)

  Each Person's Share = Total Bill ÷ Number of Members

  Example:
  ─────────────────────────────────────────────
  Bill      :  ₹1,000
  Tip (15%) :  ₹150
  Tax (5%)  :  ₹50
  ─────────────────────────────────────────────
  Total     :  ₹1,200
  Members   :  4
  Per Head  :  ₹300  each
  ─────────────────────────────────────────────
```

### Settlement Algorithm
```
  INPUT: List of (person, balance) pairs
         Positive balance = owed money
         Negative balance = owes money

  ALGORITHM:
  ┌─────────────────────────────────────┐
  │  1. Calculate net balance per member│
  │  2. Sort: creditors vs debtors      │
  │  3. Match largest debtor with       │
  │     largest creditor                │
  │  4. Settle — carry remainder        │
  │  5. Repeat until all balanced       │
  └─────────────────────────────────────┘

  OUTPUT: Minimum number of transactions
          to settle all debts
```
